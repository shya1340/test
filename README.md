# 다이아몬드 크로니클 (Diamond Chronicle)

KBO 2025시즌 실제 기록을 기반으로 한 야구 카드 매니지먼트 웹앱입니다. 넥슨 "프로야구매니저(프야매)"의 카드 수집·육성·경기 진행 방식을 참고해 만들었습니다.

## 실행 방법

별도 빌드 과정이 필요 없는 순수 HTML/CSS/JS 단일 파일입니다.

- **그냥 열어보기**: `index.html`을 더블클릭하거나 브라우저에서 열면 바로 실행됩니다.
- **GitHub Pages로 배포하기**:
  1. 이 저장소의 Settings → Pages 메뉴로 이동
  2. Branch를 `main`(또는 배포용 브랜치), 폴더를 `/ (root)`로 지정 후 저장
  3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속 가능

> ⚠️ **계정 동기화(클라우드 저장)와 여러 명이 같은 리그를 공유하는 기능은 Claude.ai 아티팩트 환경(`window.claude` API) 전용입니다.** GitHub Pages 등 일반 웹 호스팅에 올리면 이 API 자체가 없어서 해당 기능이 전부 비활성화되고, 브라우저 로컬 저장소(localStorage)만 사용하는 1인 플레이 모드로 자동 전환됩니다.
>
> 참고로 Claude.ai 아티팩트 환경에서도 계정 동기화·공유 리그 기능은 **아티팩트 소유자와 같은 조직(Team/Enterprise) 소속이거나 게스트로 초대된 사람**에게만 열립니다. 서로 다른 개인 계정(지인·친구)끼리는 이 기능을 쓸 수 없는 것으로 확인됐습니다 — 여러 명이 실시간으로 같은 리그를 공유하려면 별도의 백엔드(Firebase, Supabase 등)를 직접 연동해야 합니다.

## 주요 기능

- **카드 도감**: 10개 구단, 총 547장의 선수 카드 (2025시즌 실제 기록 기반 능력치)
  - 타자: 파워·컨택·선구·스피드·수비
  - 투수: 체력·구속·구위·변화구·제구·정신력
  - 코스트(1~10, 별 표시) 및 등급(일반/레어/에이스/레전드)
- **입단(온보딩)**: 팀 선택 시 코스트 6 이하 선수 중 타자 1명·투수 1명을 직접 골라 시작, 뽑기권 30장 지급
- **상점**: 화폐(냥) 또는 뽑기권으로 선수 카드/스킬블록 뽑기
- **라인업 편성**: 보유 카드로 타순(9명) 및 투수진(선발5·중계4·셋업1·마무리1) 구성, 다른 팀에서 뽑은 선수도 기용 가능
- **경기 시뮬레이션**: 실제 능력치 기반 9이닝 자동 진행, 점수 상황별 투수 교체(필승조/박빙조/추격조/패전조, 홀드/세이브 상황 자동 투입), 끝내기·노히트노런 하이라이트
- **정규시즌 자동 진행**: 일~금 매시 정각(07~24시) 1경기, 팀당 108경기, 접속하지 않은 동안에도 자동 진행
- **포스트시즌**: KBO 실제 규정(와일드카드→준플레이오프→플레이오프→한국시리즈)
- **훈련**: 스킬블록 장착, 유학을 통한 영구 능력치 상승
- **리그 리더보드**: 인게임 누적 기록 기준 타율/홈런/타점/평균자책점/탈삼진 TOP5
- **닉네임 로그인 화면**: 독립된 로그인 페이지 스타일 (추후 정식 이메일/비밀번호 회원가입으로 확장 예정)
- **카드 뒤집기**: 선수 카드를 우클릭하면 확대, 한 번 더 클릭하면 실제 시즌 성적/인게임 성적이 있는 뒷면으로 전환
- **리그 참가(Claude 아티팩트 환경 전용, 조직/게스트 한정)**: 계정별로 팀을 등록해 같은 조직 내에서 시즌을 공유

## 알려진 한계

- 도루(일부 팀), 수비 세부 기록(팀별 데이터 완성도 상이) 등 원본 데이터에 없는 항목은 추정치이거나 기본값입니다.
- 경기 시뮬레이션은 단순화된 확률 모델이며, 연장전은 지원하지 않습니다(동점 시 재시뮬레이션으로 대체).
- GitHub Pages 등 일반 호스팅에서는 계정 동기화·멀티플레이어 기능이 비활성화되고 로컬 저장소 기반 1인 플레이로 동작합니다.
- 여러 명이 실시간으로 같은 리그를 공유하는 기능은 같은 조직 소속 계정 간에만 동작이 확인되었고, 개인 계정 간 게스트 초대로는 검증되지 않았습니다.

## 기술 스택

순수 HTML/CSS/JavaScript (프레임워크 없음, 외부 의존성 없음)
